# HTML demo corpus

Four hand-written pages with the same link structure as the CS50 "corpus0" example
(1 -> 2; 2 -> 1, 3; 3 -> 2, 4; 4 -> 2). Each page also contains links that the crawler
must ignore: external URLs, mailto, a protocol-relative URL, fragment-only links, a
self-link, duplicate links, a missing target, and paths into or out of a sub-folder.
